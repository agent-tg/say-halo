# Say Halo 0.8.23

- Adds optional iCloud sync for word replacements, including learned corrections. Enable **Sync word replacements with iCloud** on each Mac using the same iCloud account.
- Preserves offline edits and deletions, with status messages when iCloud is unavailable or storage is full.
- Keeps microphone choices, shortcuts, transcription history, word removals, and output formatting on each Mac.
