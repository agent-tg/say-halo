# Say Halo 0.8.29

- New **Automatically check for updates** switch in Settings → General. It shows whether Say Halo keeps itself up to date.
- Automatic updates are turned back on for every install. Some Macs had them switched off with no way to see it, so new versions never showed up on their own.
- Say Halo now checks every 4 hours instead of once a day. New versions download in the background, and an Install row appears in the Say Halo menu when one is ready.

Existing settings, saved word replacements, models, and permissions are preserved. You can turn automatic updates off again in Settings.
