# Say Halo 0.8.13

Automatic updates work again.

- Say Halo now checks for updates at its new home under the agent-tg GitHub account. Earlier versions pointed at an address that no longer exists, so this is a one-time manual install; every update after this arrives automatically.
- The "View Releases" link in About points at the new releases page.

Your shortcuts, microphone selection, models, and personal settings stay the same.
